# RouteRU

Rutgers smart route planner — a student-scale full-stack project centered on graph algorithms.

## Goal
Build the project one layer at a time. The starter intentionally contains structure and small placeholders, not the finished routing solution.

## Planned stack
- Frontend: React + TypeScript + Vite
- Backend: Python + FastAPI
- Core CS: weighted graphs + Dijkstra's shortest-path algorithm

## First milestone
Represent a tiny Rutgers map as a graph in Python and understand every part of it before implementing Dijkstra.

## Structure
- `backend/` — Python/FastAPI and routing logic
- `frontend/` — React/TypeScript UI
- `PROJECT_PLAN.md` — scope and milestones

Do not add a database, authentication, AI, Redis, or other infrastructure unless the project later has a real need for it.
