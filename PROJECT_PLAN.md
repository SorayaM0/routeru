# RouteRU Project Plan

## V1
A user selects a Rutgers starting location and destination. RouteRU calculates a shortest route and estimated travel time using our own graph representation and shortest-path implementation.

## V1 includes
- Rutgers location dataset (small curated set first)
- Weighted graph / adjacency list
- Dijkstra's shortest-path algorithm
- Backend route endpoint
- React start/destination selectors
- Route result + estimated time
- Input/error handling
- Unit tests for routing logic
- README + deployment

## Deliberately out of V1
- User accounts
- PostgreSQL
- AI/chatbot
- Redis
- Live bus tracking
- Social features
- Microservices

## Milestones
1. Python graph fundamentals
2. Graph data model
3. Dijkstra implementation
4. Tests
5. FastAPI API
6. React UI
7. Connect frontend/backend
8. Rutgers data refinement
9. Polish, README, deployment
